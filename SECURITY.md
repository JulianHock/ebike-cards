# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue.
Report it privately under **Security → Report a vulnerability** in this repository instead.

Include the affected version, the steps to reproduce it and what an attacker could do with it.
Leave out personal data, access tokens and Home Assistant URLs.

This is a hobby project, so there is no guaranteed response time.
